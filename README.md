# 🏗 Поиск КЕР в ССР

Веб-приложение для сметчиков и инженеров ПТО.
Позволяет быстро находить Комплексные единичные расценки (КЕР) в базе ССР
и формировать Ведомость объёмов работ (ВОР).

## 🚀 Возможности

- 🔍 Поиск по ключевым словам
- 📂 Фильтрация по уровням иерархии Л3
- 📋 Просмотр карточки расценки (иерархия, состав работ, ФЕР)
- 📊 Формирование ВОР с экспортом в Excel
- 👁 Гибкая настройка отображения служебных расценок

## 🛠 Технологии

- Python 3.11+
- Streamlit
- Pandas
- openpyxl / xlsxwriter

## 💻 Локальный запуск

```bash
pip install -r requirements.txt
streamlit run app.py
